
# Flash Cards

A flash card application built with React, TypeScript, and Vite.

## Features

- Create and manage flash cards.
- Study questions and answers.
- Track study progress.

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```
